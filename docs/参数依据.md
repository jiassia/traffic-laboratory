# 车辆与天气参数依据

核查日期：2026 年 10 月 28 日。本文记录来源、采用值和工程选择，配合 `src/vehicle-profiles.mjs` 使用。

本次检索采用多来源核查：直接阅读作者论文、作者模型说明及 FHWA 官方资料，并以 CrossRef 核对可访问的论文元数据。论文提供可复用的模型参考，具体城市的准确预测仍需要当地交通观测校准。

## 1. 速度的含义

`maxSpeed` 表示驾驶者在无前车、无信号及无限速约束时的自由流期望速度，单位为 km/h。它不等于车辆性能最高速度，也不等于道路法定限速。城市道路限速、前车、停止线、曲率和可用视距共同约束实际速度。

作者 IDM 说明明确要求在限速生效时降低期望速度。因此，参考参数中的汽车 120 km/h 不表示城市画面中的车辆应以 120 km/h 行驶。项目的 30、50、70 km/h 道路选项是可编辑的道路情景初值，不能视为对所有真实道路限速的概括。

## 2. 采用的车辆参考组

| 参数 | 汽车参考组 | 卡车参考组 | 公交舒适目标组 |
|---|---:|---:|---:|
| 自由流期望速度，km/h | 120 | 85 | 80，工程代理 |
| 加速度参数 a，m/s² | 1.4 | 0.7 | 1.0，舒适目标 |
| 舒适制动参数 b，m/s² | 2.0 | 2.0 | 1.0，舒适目标 |
| 期望净时距 T，s | 1.5 | 2.0 | 2.0，工程代理 |
| 静止保险杠净间距 s0，m | 2.0 | 2.0 | 2.0，工程代理 |

汽车与卡车组直接采用 Kesting、Treiber、Schönhof 与 Helbing 的作者稿第 12 页 Table 2。该表是高速路仿真所用参考参数组，没有按本项目八种外观模型分别进行现场标定。[S1]

轿车、两厢车、SUV 和出租车共用汽车组。皮卡和厢式车暂作轻型车辆代理，也共用汽车组；没有为它们虚构独立的实测速度或加速差异。车身尺寸仍来自各自模型。载重、发动机、动力类型和驾驶行为差异不由外观名称自动确定。

公交研究使用伦敦 388 线一辆 Enviro 400H 的正常往返记录。作者稿 Table 2 的观测最大加速度为 1.33 m/s²，最大制动幅值为 1.82 m/s²；论文进一步研究将加速和制动幅值限制至 1.0 m/s² 的乘客舒适目标。[S4] 因此，本项目把 1.0 用作公交的日常舒适参数。该值不作为车辆动力能力或紧急制动能力的绝对上限。公交的 80 km/h、2.0 s 和 2.0 m 尚属大车代理初值。

## 3. IDM 参考值为何不只采用一张表

Treiber、Hennecke 与 Helbing 的 2000 年原论文在 Table I 使用 v0=120 km/h、T=1.6 s、a=0.73 m/s²、b=1.67 m/s²、δ=4 和 s0=2 m，研究同质车辆的高速路拥堵。[S2] 本项目采用后续汽车与卡车分组的 Table 2，以表达两组车辆的差异，不把不同论文的参数拼成一个声称逐项实测的配置。

作者当前模型说明中的 a=0.3 m/s² 是为了加强走停现象而使用的演示值，页面明确解释了这一点。不能因为它出现在作者网页表格中，就把它当作日常驾驶的统一加速度。[S3]

T 是期望跟驰净时距，不是司机显式反应延迟，也不是积分步长。界面中的时距倍率调整 T；固定仿真步长用于数值求解。将这些量混称“反应时间”会误解模型含义。

## 4. 天气参考

| 天气预设 | 速度倍率 | 来源所描述的条件 |
|---|---:|---|
| 晴朗 | 1.000 | 基准情景 |
| 降雨 | 0.825 | 湿路面城市干道速度下降 10% 至 25%，取中点 |
| 降雪 | 0.650 | 积雪或雪泥城市干道速度下降 30% 至 40%，取中点 |
| 低能见度 | 0.890 | 高速公路低能见度平均速度下降 10% 至 12%，仅作跨场景参考 |

上述范围来自 FHWA 的天气影响汇总。[S5] 它们描述不同地点和条件下的统计变化，并非同一天气类别的普遍常数。低能见度的高速公路数值不构成城市雾天的独立校准。

`friction` 在当前代码中是制动倍率，不是轮胎与路面的实测摩擦系数。晴、雨、雾、雪的 1、0.68、0.9、0.4 倍率和 180、100、45、70 m 可用视距均属工程情景值。`WEATHER_REFERENCE` 单独标出了这些假设。

实际速度还可能受视距安全约束限制，故不保证画面中的平均速度恰好下降 17.5%、35% 或 11%。车型混合、曲线、拥堵和信号也会改变速度。若要验证某城市雨天的数值，应使用同一路段、相同需求条件下的当地观测数据。

## 5. 尚未从文献校准的情景

- 每行程的随机故障、随机违规概率没有本项目暴露量数据支持。正常场景宜设为 0，用户主动启用时作为情景注入，不能解释为现实事故率。
- 转弯横向加速度阈值、紧急制动上限、信号损失时间和路口冲突保守包络属于模型实现或工程初值，需要独立验证。
- 路口车道连接与缩道安全检查属于代码及行为验证，不能代替真实交通容量标定。
- 当前没有采集本地车型轨迹、载重、坡度、摩擦和视距数据，不能将所有场景表述为已经符合现实。FHWA 将校准定义为针对特定条件的时变观测进行参数调整。[S6]
